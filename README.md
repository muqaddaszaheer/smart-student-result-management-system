# Smart Student Result Management System

A Python-based student result management system developed as an academic project.

## About the Project

The Smart Student Result Management System is a simple, menu-driven program designed to manage student results. It allows users to add student records, enter marks for five subjects, calculate results, and view student performance.

This project was created to practice fundamental Python programming concepts and apply them in a practical program.

## Features

- Add student records
- Enter marks for five subjects
- Validate marks from 0 to 100
- Calculate total marks, average, and percentage
- Calculate grades
- Display pass or fail results
- View a student's result
- Search for a student by roll number
- View all student records
- Display subject-wise performance
- Identify the strongest and weakest subject
- Menu-driven interface using `match-case`
